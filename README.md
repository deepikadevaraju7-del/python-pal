# PyCard — Python Q&A Chatbot

A responsive single-page chatbot that answers Python questions in plain English
using a curated knowledge base and local retrieval matching (no external AI APIs).

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase (knowledge base storage)
